01. Client-Side Processing Architecture Infrastructure

Unlike standard online file conversion services, FreeZip-Tools performs all file manipulation, code parsing, cryptographic hashing, and image packaging entirely within your web browser (Google Chrome, Firefox, Safari, Edge).

  • No Payload Transmissions: When you select or drag images for the Image to ZIP utility, those files are read directly into browser memory (RAM) via JavaScript File and Blob APIs.
  • Zero Remote Storage: There is no backend server receiving uploads, no temp folders, and no Amazon S3 or Google Cloud storage buckets storing your files.
  • Network Isolation: You can disconnect your internet connection immediately after the page loads and continue converting files or formatting code offline.
02. Zero Telemetry & Logging Policy Telemetry

We believe utility portals should remain tools, not tracking beacons. FreeZip-Tools does not maintain user activity databases:

What We Never Collect

We do not record IP addresses, query inputs, generated cryptographic hashes, passwords, or metadata from converted assets.

Pure static hosting with instantaneous page render speeds and zero invasive third-party analytics pixels.

03. LocalStorage & Cookie Transparency Storage

FreeZip-Tools does not set any advertising, tracking, or cross-site fingerprinting cookies.

Key: freezip_theme
Purpose: Stores your UI appearance choice ('light' or 'dark').
Location: 100% inside your browser's window.localStorage.

Clearing your browser cache or browser history completely removes this key at any time.

04. Third-Party CDNs & Static Assets Dependencies

To provide lightweight static delivery, FreeZip-Tools loads public asset bundles from industry-standard content delivery networks:

  • Cloudflare CDNJS: Delivers Font Awesome vector icons and JSZip for local compression.
  • Tailwind CSS CDN: Delivers runtime styling rules.
  • Google Fonts: Delivers modern typography (Plus Jakarta Sans & JetBrains Mono).

These requests contain standard HTTP headers (e.g., user-agent) necessary to download styles, with no identifying cookies transferred.
